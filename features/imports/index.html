Import et export

Vos relevés, sans service tiers.

Importez vos relevés sans service tiers, corrigez ce qui doit l’être, et défaites un import en un geste.

Ce qu’il y a dedans

  • Assistant CSV : les colonnes reconnues (date, montant ou débit/crédit, libellé…) se corrigent ; l’aperçu montre les totaux avant d’importer.
  • Corriger ligne par ligne : décochez, modifiez ou ignorez une ligne avant l’import.
  • Noms nettoyés : « CARTE CARREFOUR MARKET » devient « Carrefour Market » ; le libellé de la banque reste dans le mémo.
  • Catégorie proposée : d’après vos règles, votre historique, puis quelques noms connus.
  • Écran « À vérifier » : après l’import, relisez les catégories proposées ; vos corrections sont reprises pour les prochaines transactions du même nom.
  • Doublons : les transactions déjà présentes sont repérées et ignorées.
  • Solde actuel : pour un relevé sans solde, saisissez le solde de votre banque ; l’app en déduit le solde d’ouverture.
  • Ordre du relevé : à date égale, les transactions restent dans l’ordre de la banque.
  • Activité PayPal : un paiement par achat, avec son commerçant, dans un compte PayPal relié aux lignes PayPal de la banque.
  • Un lot, une étiquette : une étiquette permet de retrouver ce qui vient d’être importé ; l’import s’annule en entier.
  • Formats : CSV, OFX, QIF, MT940 et CAMT.053 ; import de fichiers XHB et d’archives Actual Budget.
  • Profils de banque : la mise en page d’une banque est mémorisée.
  • Dossier surveillé : déposez vos relevés dans un dossier, l’app les importe seule, sans doublons.
  • Export : CSV, QIF, sauvegarde JSON, rapports en PDF.
