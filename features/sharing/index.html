Compte partagé

Un compte joint, des droits précis.

Partagez un seul compte, par exemple un compte joint, avec des droits choisis pour chaque personne.

Ce qu’il y a dedans

  • Un compte, pas tout le registre : seuls les comptes que vous choisissez sont partagés.
  • Trois niveaux de droits : lecture seule, saisie (la personne modifie ses propres lignes) ou modification de tout.
  • Par iCloud : un profil par personne (nom, e-mail, droits), un bouton « Inviter par e-mail » qui prépare le message avec le lien ; la personne ouvre le lien et le compte apparaît chez elle.
  • Ou par un dossier que l’autre personne peut ouvrir (iCloud Drive partagé, Dropbox, Syncthing). Dans les deux cas, aucun serveur de l’éditeur.
  • Signatures : les droits sont protégés par des signatures P-256 ; un fichier modifié sans droit est refusé.
  • Activité : le Journal des modifications montre ce que les autres personnes ont ajouté ou modifié.
  • Clés : gardées dans le Trousseau, réservées à votre Mac.
