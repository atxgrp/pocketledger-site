Politique de confidentialité

Dernière mise à jour : 21 novembre 2026. Éditeur : ATX Grp — atxgrp@gmail.com

En résumé

Pocket Ledger fonctionne sur votre Mac, votre iPhone et votre iPad. Vos comptes, transactions, budgets et pièces jointes restent chez vous. ATX Grp ne reçoit aucune de vos données : pas de compte à créer, pas de publicité, pas de mesure d’audience, pas de pistage, aucun service d’analyse tiers.

Où sont vos données

  • Un fichier lisible (ledger.json) et un dossier de pièces jointes, dans ~/Library/Application Support/PocketLedger ou dans le dossier que vous choisissez dans Réglages → Données.
  • Le fichier n’est lisible que par votre session macOS (droits 600).
  • Les clés d’accès aux banques et vos clés de signature de comptes partagés sont gardées dans le Trousseau de votre Mac, jamais dans le fichier de données.
  • Des copies automatiques du fichier (une par jour, 14 jours et une par mois) sont gardées dans ~/Library/Application Support/PocketLedger/Backups, avec les mêmes protections. Vous pouvez les désactiver dans Réglages → Données.
  • Un journal des modifications (ce qui a changé et quand) est gardé sur ce Mac seul, dans ~/Library/Application Support/PocketLedger/Journal ; « Effacer toutes mes données » le supprime aussi.
  • Les sauvegardes peuvent être chiffrées par mot de passe (AES-256-GCM). Sans le mot de passe, personne, ATX Grp compris, ne peut les lire ni les récupérer.

Connexions réseau

L’app ne se connecte à Internet que dans ces cas :

  • Taux de change : seulement si un de vos comptes est en devise étrangère (ou si vous cliquez sur « Mettre à jour »), et au plus toutes les 12 heures, l’app télécharge les taux de référence publiés par la Banque centrale européenne. Aucune donnée personnelle n’est envoyée ; votre adresse IP est visible de la BCE comme pour toute page web.
  • Cours des cryptomonnaies : seulement si vous saisissez des cryptomonnaies. L’app demande les prix à CoinGecko ; seuls les symboles des actifs suivis sont envoyés, avec votre adresse IP.
  • Mises à jour (facultatif, désactivé par défaut) : si vous activez la vérification automatique ou cliquez sur « Rechercher maintenant », l’app interroge le serveur de l’éditeur (son adresse est affichée dans Réglages → Général). Seules la version de l’app et celle de la bibliothèque de mises à jour sont transmises, avec votre adresse IP ; aucun profil de votre Mac n’est envoyé. Le flux est hébergé sur GitHub Pages : GitHub reçoit alors votre adresse IP, selon sa propre politique de confidentialité.
  • Connexion bancaire : seulement si vous la configurez. Vos transactions transitent entre votre banque, le fournisseur choisi (GoCardless ou Enable Banking) et votre Mac, avec les clés que vous avez vous-même créées chez ce fournisseur. ATX Grp n’est pas dans le circuit.
  • iCloud : seulement si vous activez la synchronisation. Vos données (le registre et les pièces jointes, un enregistrement par fichier) sont alors stockées dans votre espace iCloud privé (CloudKit), géré par Apple selon sa propre politique. ATX Grp n’y a pas accès. Un fichier que plus aucune transaction n’utilise est retiré d’iCloud après une semaine.
  • Dossier partagé ou compte partagé : si vous placez des données dans un dossier synchronisé (iCloud Drive, Dropbox, Syncthing…) ou partagez un compte, elles sont visibles par les personnes et par le service qui gèrent ce dossier.

Autorisations du système

  • Calendrier : seulement si vous activez l’affichage de vos échéances dans l’app Calendrier. L’app écrit dans un calendrier « Pocket Ledger » et ne lit pas vos autres événements.
  • Touch ID / mot de passe : le verrouillage utilise le système ; l’app ne reçoit jamais votre empreinte ni votre mot de passe.
  • Lecture de tickets : la reconnaissance du texte se fait sur votre Mac (Vision) ; l’image ne quitte pas l’appareil.
  • Siri, Raccourcis, widgets, saisie rapide dans la barre de menus : tout se passe localement sur votre Mac.
  • Notifications : les rappels (échéances, enveloppes, soldes) sont des notifications locales ; rien n’est envoyé à un serveur.
  • Spotlight (facultatif, désactivé par défaut) : si vous l’activez, les bénéficiaires, montants et catégories de vos transactions sont ajoutés à l’index de recherche de votre Mac, visibles même quand l’app est verrouillée. Désactiver l’option efface cet index.

Sur iPhone et iPad

Les mêmes principes s’appliquent. Face ID ou Touch ID verrouillent l’app : l’app ne reçoit jamais votre visage ni votre empreinte. L’appareil photo sert seulement à scanner un ticket ; le texte est lu sur l’appareil et l’image ne le quitte pas. Les widgets, Siri et Raccourcis fonctionnent localement.

Ce site web

Le site est hébergé par GitHub Pages : GitHub reçoit votre adresse IP et des données techniques de connexion, selon sa propre politique. L’éditeur n’utilise ni cookie, ni mesure d’audience, ni service tiers (pas de police, de vidéo ni de carte externe). Votre choix de langue est mémorisé dans le stockage local de votre navigateur (clé « plLang »), sans être envoyé à personne ; il est nécessaire pour retrouver la langue choisie et peut être effacé depuis votre navigateur. Aucun consentement n’est donc demandé. Le bouton « Gérer mes cookies » du pied de page ouvre un panneau qui le rappelle ; si un service facultatif était un jour ajouté, il ne se lancerait qu’après votre accord, votre choix serait mémorisé six mois au plus dans ce même stockage local (clé « plConsent ») et vous pourriez le changer à tout moment.

Si vous nous écrivez

Le formulaire de contact du site ne transmet rien lui-même : il prépare un message dans votre application Mail, que vous envoyez ou non. Responsable du traitement : l’éditeur (ATX Grp), joignable à atxgrp@gmail.com. Données : votre adresse e-mail et le contenu de votre message. Finalité : vous répondre. Base légale : l’intérêt légitime à répondre à votre demande. Destinataires : aucun, hors le service de messagerie utilisé. Durée : les échanges sont supprimés au plus tard douze mois après le dernier message.

Bases légales des connexions réseau

Taux de change, cours de cryptomonnaies, mises à jour, connexion bancaire et iCloud ne se déclenchent que si vous activez la fonction concernée ou cliquez sur le bouton correspondant : votre action en est la base.

Durée de conservation et suppression

Vos données restent tant que vous les gardez. Pour tout effacer en une fois : Réglages → Données → Effacer toutes mes données… (après confirmation, l’app supprime vos données, pièces jointes, copies, clés du Trousseau, index Spotlight, rappels et réglages sur ce Mac, ainsi que la copie iCloud si la synchronisation était active). Vous pouvez aussi, à la main, fermer l’app et supprimer son dossier de données.

Vos droits

ATX Grp ne détient aucune donnée de votre registre financier. Vous restez maître de vos données : vous pouvez les exporter (CSV, QIF, sauvegarde) et les supprimer à tout moment. Si vous nous écrivez, nous utilisons votre message et votre adresse e-mail uniquement pour vous répondre. Pour exercer vos droits (accès, rectification, effacement, opposition, limitation, portabilité) ou poser une question : atxgrp@gmail.com. Vous pouvez aussi saisir l’autorité de protection des données de votre pays (en France, la CNIL, cnil.fr).

Modifications

Cette politique peut évoluer avec l’app ; la date de mise à jour figure en haut de la page.
