Politique de confidentialité

Dernière mise à jour : 30 octobre 2026. Éditeur : ATX Grp — atxgrp@gmail.com

En résumé

Pocket Ledger fonctionne sur votre Mac. Vos comptes, transactions, budgets et pièces jointes restent chez vous. ATX Grp ne reçoit aucune de vos données : pas de compte à créer, pas de publicité, pas de mesure d'audience, pas de pistage, aucun service d'analyse tiers.

Où sont vos données

  • Un fichier lisible (ledger.json) et un dossier de pièces jointes, dans ~/Library/Application Support/PocketLedger ou dans le dossier que vous choisissez dans Réglages → Données.
  • Le fichier n'est lisible que par votre session macOS (droits 600).
  • Les clés d'accès aux banques et vos clés de signature de comptes partagés sont gardées dans le Trousseau de votre Mac, jamais dans le fichier de données.
  • Des copies automatiques du fichier (une par jour, 14 jours et une par mois) sont gardées dans ~/Library/Application Support/PocketLedger/Backups, avec les mêmes protections. Vous pouvez les désactiver dans Réglages → Données.
  • Les sauvegardes peuvent être chiffrées par mot de passe (AES-256-GCM). Sans le mot de passe, personne, ATX Grp compris, ne peut les lire ni les récupérer.

Connexions réseau

L'app ne se connecte à Internet que dans ces cas :

  • Taux de change : seulement si un de vos comptes est en devise étrangère (ou si vous cliquez sur « Mettre à jour »), et au plus toutes les 12 heures, l'app télécharge les taux de référence publiés par la Banque centrale européenne. Aucune donnée personnelle n'est envoyée ; votre adresse IP est visible de la BCE comme pour toute page web.
  • Cours des cryptomonnaies : seulement si vous saisissez des cryptomonnaies. L'app demande les prix à CoinGecko ; seuls les symboles des actifs suivis sont envoyés, avec votre adresse IP.
  • Mises à jour (facultatif, désactivé par défaut) : si vous activez la vérification automatique ou cliquez sur « Rechercher maintenant », l'app interroge le serveur de l'éditeur (son adresse est affichée dans Réglages → Général). Seules la version de l'app et celle de la bibliothèque de mises à jour sont transmises, avec votre adresse IP ; aucun profil de votre Mac n'est envoyé. Le flux est hébergé sur GitHub Pages : GitHub reçoit alors votre adresse IP, selon sa propre politique de confidentialité.
  • Connexion bancaire : seulement si vous la configurez. Vos transactions transitent entre votre banque, le fournisseur choisi (GoCardless ou Enable Banking) et votre Mac, avec les clés que vous avez vous-même créées chez ce fournisseur. ATX Grp n'est pas dans le circuit.
  • iCloud : seulement si vous activez la synchronisation. Vos données sont alors stockées dans votre espace iCloud privé (CloudKit), géré par Apple selon sa propre politique. ATX Grp n'y a pas accès.
  • Dossier partagé ou compte partagé : si vous placez des données dans un dossier synchronisé (iCloud Drive, Dropbox, Syncthing…) ou partagez un compte, elles sont visibles par les personnes et par le service qui gèrent ce dossier.

Autorisations du système

  • Calendrier : seulement si vous activez l'affichage de vos échéances dans l'app Calendrier. L'app écrit dans un calendrier « Pocket Ledger » et ne lit pas vos autres événements.
  • Touch ID / mot de passe : le verrouillage utilise le système ; l'app ne reçoit jamais votre empreinte ni votre mot de passe.
  • Lecture de tickets : la reconnaissance du texte se fait sur votre Mac (Vision) ; l'image ne quitte pas l'appareil.
  • Siri, Raccourcis, widgets, saisie rapide dans la barre de menus : tout se passe localement sur votre Mac.
  • Notifications : les rappels (échéances, enveloppes, soldes) sont des notifications locales ; rien n'est envoyé à un serveur.
  • Spotlight (facultatif, désactivé par défaut) : si vous l'activez, les bénéficiaires, montants et catégories de vos transactions sont ajoutés à l'index de recherche de votre Mac, visibles même quand l'app est verrouillée. Désactiver l'option efface cet index.

Durée de conservation et suppression

Vos données restent tant que vous les gardez. Pour tout effacer : fermez l'app, supprimez le dossier de données (et, si vous l'aviez activée, les données Pocket Ledger dans Réglages Système → iCloud), puis supprimez les entrées « Pocket Ledger » de votre Trousseau si vous le souhaitez.

Vos droits

ATX Grp ne détient aucune donnée de votre registre financier. Vous restez maître de vos données : vous pouvez les exporter (CSV, QIF, sauvegarde) et les supprimer à tout moment. Si vous nous écrivez, nous utilisons votre message et votre adresse e-mail uniquement pour vous répondre. Pour exercer vos droits (accès, rectification, effacement, opposition) ou poser une question : atxgrp@gmail.com. Vous pouvez aussi saisir l'autorité de protection des données de votre pays (en France, la CNIL).

Modifications

Cette politique peut évoluer avec l'app ; la date de mise à jour figure en haut de la page.
